プライバシーポリシー

本ポリシーは、Seionan が自社の宿泊施設運営に利用する社内業務システム 「Minpaku Automation」における情報の取扱いについて定めるものです。

1. 利用目的

Minpaku Automation は、宿泊施設の予約管理、ゲスト対応、施設情報管理、 清掃・通知、設備運用その他の宿泊施設運営に必要な業務を自動化・効率化するために利用します。

2. Google ユーザーデータへのアクセス

Minpaku Automation は、業務上必要な範囲で Google Gmail、Google Drive、 Google Sheets、Google Calendar その他の Google サービス上のデータにアクセスすることがあります。

主な利用目的は以下のとおりです。

  • 予約・ゲスト関連メールの取得、解析および業務データへの反映
  • 宿泊施設運営に必要な文書・表計算データの保存、参照および更新
  • 予約・運用スケジュールの参照および同期
  • 施設運営に必要な通知、自動処理および障害対応

3. データの利用・共有

取得した情報は、上記の宿泊施設運営目的のためにのみ利用します。 Google ユーザーデータを広告目的で利用したり、販売したりすることはありません。

法令に基づく場合その他正当な理由がある場合を除き、業務上必要な範囲を超えて Google ユーザーデータを第三者に提供しません。

4. データの保存と保護

業務上必要なデータは、Google Workspace 関連サービス、業務用データベース、 その他の運用基盤に保存される場合があります。

アクセス権限を必要な利用者およびシステムに限定し、 認証情報や機密情報が不必要に公開されないよう適切な管理を行います。

5. データの保持と削除

情報は、宿泊施設運営、法令上の義務、障害調査その他の正当な業務上の必要性がある期間に限り保持し、 不要となった情報は合理的な方法で削除または利用停止します。

6. Google API Services User Data Policy

Minpaku Automation による Google API から取得した情報の利用および他のアプリへの転送は、 Google API Services User Data Policy に準拠し、Limited Use の要件を含む適用条件に従います。

7. 対象範囲

Minpaku Automation は Seionan の社内利用を目的としたシステムであり、 一般利用者向けに提供・販売されるサービスではありません。
